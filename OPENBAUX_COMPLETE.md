## 🏃‍♂️ **HOW TO RUN**

### **Option 1: Full Development Setup**
```bash
# Install all dependencies
npm run install-all

# Start both backend & frontend
npm run dev
```

### **Option 2: Individual Services**
```bash
# Backend only (Port 5000)
cd server && npm start

# Frontend only (Port 3000)
cd web && npm start
```
